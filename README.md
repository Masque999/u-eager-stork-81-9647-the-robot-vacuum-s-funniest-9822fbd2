# The Robot Vacuum's Funniest Excuse

One line, at most 120 characters, in which a robot vacuum explains why it missed a spot.

Entry: `I did not miss that spot on purpose; the dust bunny filed a restraining order, and I respect the law.`

Run: `python3 main.py` (writes the sentence to `/output/entry.txt`).
